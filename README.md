Projeto de uso exclusivo de **Caio Firmino**.

## Funcionalidades

- Cadastro e consulta de lojas e produtos.
- Contagem de estoque por visita, com rascunho e histórico.
- Comparação entre visitas e acompanhamento das variações de estoque.
- Filtros por período, loja e laboratório.
- Relatórios e exportação em Excel, CSV e PDF.
- Interface responsiva, com temas claro e escuro.

## Tecnologias

Interface em HTML, CSS e JavaScript. API em Node.js, SQLite na execução local e PostgreSQL no Neon para a versão online. Python auxilia na importação de planilhas. Hospedagem na Vercel.
